A checklist for Terry and Brian. Nothing here has been run against any real database.

From the one-time SQL-safety audit on branch `cook/sql-audit` (Nov 27 2026). Every Worker query binds its values with `?`.
The two places that put names into SQL text are now fixed constants or an allow-list. `npm run check:sql-audit -- --inventory`
prints every Worker SQL call with its verdict. The rows below are
the things this cook was not allowed to change, or that need a person to decide.
