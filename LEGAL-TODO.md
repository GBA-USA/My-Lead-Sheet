It reads every text file of the build except source maps, and the script files of the Worker and `functions`. Its address rule catches an `http`, `https`, `ws` or `wss` address, a protocol-relative one after a quote, `(` or `=`, and a `stun` or `turn` address with a dotted or IP host, when one is written there with no audit row. It does not see an address with escaped slashes (`https:\/\/`), a protocol-relative address after the first entry of a `srcset`, a one-word `stun` host, or an address the app puts together while it runs. Its price rule only matches a fixed list of button words, so it is a tripwire. When a real paywall is built, a person has to read the screen against the renewal rules.
